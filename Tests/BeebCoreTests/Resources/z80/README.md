Z80 instruction exercisers
--------------------------

`zexdoc.com` and `zexall.com` are Frank D. Cringle's Z80 instruction set
exercisers (Copyright (C) 1994 Frank D. Cringle), CP/M programs that run
each instruction group over many machine states and compare a CRC of the
results with one taken from a real Z80. ZEXDOC checks the documented flags
only; ZEXALL checks all of them, including the undocumented bits 3 and 5.

from YAZE-AG 2.51.3 by Andreas Gerlich), which also has the source.
